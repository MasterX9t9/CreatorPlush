# Data Sources Specification: CreatorPulse

*Refer to the full data sources and methodology document in [docs/DATA-SOURCES.md](file:///d:/1.%20Ai%20Dev/2.%20YouuTube%20UP/docs/DATA-SOURCES.md).*

## Summary of Core Data Principles:
1. **Four Classifications**: Official, Calculated, Estimated, AI-derived.
2. **Quota Handling**: Honest 429 quota exhaustion messages; never invent mock statistics.
3. **Outlier Engine**: Transparent median-based multiplier calculation.
4. **Revenue Estimations**: Clearly labeled ranges (e.g. `$1,200 – $2,100`), not fake precise decimals.
