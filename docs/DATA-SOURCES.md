# Data Sources & Methodology Specification: CreatorPulse

## 1. Core Principles of Data Integrity

Every metric in CreatorPulse is explicitly cataloged under one of four distinct classifications:

| Data Classification | Description | Typical Metrics | Display Indicator |
| :--- | :--- | :--- | :--- |
| **OFFICIAL** | Direct, unmodified data from authorized Google/YouTube APIs. | Video Views, Official Subscriber Count, Video Duration, Public Comments, Watch Time (authorized channels), Exact AdSense Revenue (authorized channels). | `Official YouTube Data` badge |
| **CALCULATED** | Derived using documented statistical formulas from official public data. | Views per Hour, Views per Day, Historical Growth Velocity, Outlier Multiplier, Channel Median Views, Consistency Index. | `Calculated Metric` badge |
| **ESTIMATED** | Derived using transparent probabilistic models or benchmarks when private data is inaccessible. | Public Channel Estimated Revenue ($800–$1,400 range), Industry RPM benchmark, Faceless Likelihood score. | `Estimated (Range)` badge |
| **AI-DERIVED** | Semantic analysis or recommendations generated by an LLM grounded on retrieved records. | Content Gaps, Title Evaluation, Thumbnail Composition Critique, Topic Suggestions. | `AI Recommendation` badge with record citations |

## 2. Primary External Data Providers

### 2.1 YouTube Data API v3
- **Usage**: Public channel metadata, video statistics, public playlists, search queries, comment threads.
- **Quota Accounting**:
  - Daily default quota: 10,000 units.
  - Video details (`videos.list`): 1 unit (batched up to 50 videos).
  - Channel details (`channels.list`): 1 unit.
  - Search queries (`search.list`): 100 units.
  - Comment threads (`commentThreads.list`): 1 unit.
- **Quota Optimization**:
  - Search deduplication and Redis caching (search results cached for 6 hours; channel profiles cached for 12 hours).
  - Bulk retrieval: always batch requests into 50-item chunks.
- **Quota Exhaustion Handling**:
  - When Google returns HTTP 403 `quotaExceeded`, the backend immediately surfaces HTTP 429:
    `"YouTube API quota exceeded for today. Next quota reset is at 00:00 PST. Stored historical data is still accessible."`
  - Under no circumstances will the system fabricate search results or fake statistics.

### 2.2 YouTube Analytics API & Reporting API
- **Usage**: Deep private analytics for creator channels that explicitly grant OAuth 2.0 authorization.
- **Required OAuth Scopes**:
  - `https://www.googleapis.com/auth/youtube.readonly`
  - `https://www.googleapis.com/auth/yt-analytics.readonly`
- **Provided Metrics**:
  - Real RPM and CPM by geography
  - Actual AdSense revenue
  - Impressions and Click-Through Rate (CTR)
  - Audience demographics (age brackets, gender distributions)
  - Traffic sources and viewer retention curves
- **Privacy Enforcement**:
  - If a user attempts to access private analytics for a competitor or unauthorized channel, CreatorPulse returns:
    `"Private creator analytics require an authorized YouTube account connection. Showing calculated public estimates."`

## 3. Statistical Calculation Methodologies

### 3.1 Statistical Outlier Score
- **Objective**: Identify videos that significantly outperform the channel's standard baseline, eliminating bias for massive channels.
- **Formula**:
  $$E(v) = \text{Median}\left(\{ V_i \mid V_i \in \text{Videos of channel published within 180 days, matching format} \}\right)$$
  $$\text{Outlier Multiplier } M = \frac{\text{Actual Video Views}}{E(v)}$$
- **Classification Tiers**:
  - **Normal**: $M < 2.0$
  - **2x Outlier**: $2.0 \le M < 5.0$
  - **5x Outlier**: $5.0 \le M < 10.0$
  - **10x Outlier**: $10.0 \le M < 20.0$
  - **20x+ Viral Outlier**: $M \ge 20.0$
- **Transparency**: Every outlier card displays both $E(v)$ (the expected median views) and $M$ so creators understand exactly why a video is flagged.

### 3.2 Revenue & RPM Range Estimation (For Public Channels)
- **Objective**: Provide a realistic revenue range without falsely claiming exact AdSense earnings.
- **Formula**:
  $$\text{RPM}_{\text{low}} = \text{Benchmark RPM for Niche & Top Geographies} \times 0.7$$
  $$\text{RPM}_{\text{high}} = \text{Benchmark RPM for Niche & Top Geographies} \times 1.3$$
  $$\text{Estimated Monthly Revenue} = \left[ \frac{\text{Monthly Views}}{1000} \times \text{RPM}_{\text{low}}, \; \frac{\text{Monthly Views}}{1000} \times \text{RPM}_{\text{high}} \right]$$
- **Rule**: Never return single-point precise numbers (e.g. `$1,432.89`) for public estimates. Always present a bracket (e.g. `$1,200 – $2,100`).

### 3.3 Niche Opportunity Score
- **Formula**:
  $$\text{Score} = w_1 \cdot \text{Demand} + w_2 \cdot (1 - \text{Competition}) + w_3 \cdot \text{MonetizationPotential}$$
  where weights ($w_1 = 0.4$, $w_2 = 0.35$, $w_3 = 0.25$) are fully disclosed to the user.
