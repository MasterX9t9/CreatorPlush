# MASTER BUILD PROMPT

## YouTube Creator Intelligence, Research & Automation Platform

You are a senior full-stack architect, UI/UX designer, data engineer, browser-extension engineer, YouTube API engineer, AI engineer, DevOps engineer, QA engineer, and security engineer.

Build a production-ready SaaS web application for YouTube creators.

The product should provide an original, legally compliant alternative to modern YouTube creator intelligence platforms.

DO NOT copy another company's source code, branding, proprietary UI, proprietary algorithms, private APIs, authentication tokens, or copyrighted assets.

Build everything from scratch using public/authorized data sources and official APIs wherever possible.

The application must have REAL FUNCTIONALITY.

NO fake buttons.
NO fake analytics.
NO placeholder dashboards pretending to work.
NO hardcoded fake YouTube statistics.
NO "coming soon" functionality unless explicitly marked as an unfinished development item.
NO mock API responses in production.
NO UI controls that do nothing.

Every major feature must connect to a real backend service, database, API, browser-extension capability, or clearly documented limitation.
